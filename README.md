Calcola il totale dei coperti paganti, l'incasso totale, il coperto medio tramite media semplice e ponderata, oltre al totale degli ordini analizzati. Queste informazioni sono visibili su due file csv denominati RISULTATI_TEST, che contiene le informazioni non sintetizzate, e SUMMARY_TEST, che contiene le statistiche descritte in precedenza.

Il file di input si ottiene dal iPraticoCloud > Statistiche - iPratico Eat > Chisure > Dettaglio chiusure di giornata > Excel. Il file scaricato è in un formato scorretto, è necessario salvarlo con nome come file xlsx (Excel).
All'apertura dell'applicazione, selezionare questo file: il programma calcolerà le statistiche e salverà i suddetti file nella stessa cartella in cui è presente l'eseguibile stesso.
